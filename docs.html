Introduction

FineCSS is a lightweight, component-based toolkit optimized for enterprise UIs. The framework ships as a single CSS bundle plus a tiny vanilla JS layer for dropdowns, modals, carousels, toasts, and scrollspy, so you can copy/paste it into any project without a build step.

Design pillars include predictable utilities, responsive layout primitives, and accessible defaults such as focus-visible outlines, reduced-motion handling, and WCAG-AA-friendly color tokens.

Documentation images rely on Placehold (600×400 mock assets) so you can preview layouts without external media; change the `/HEX/HEX?text=` params to match your own palette.

Drop FineCSS into a page with:

<link rel="stylesheet" href="/finecss/css/finecss.css">
<script src="/finecss/js/finecss.js"></script>
<script>FineCSS.init()</script>

Accessibility Guide

Keyboard navigation: dropdowns respect Enter/Space, modals trap focus, ESC closes interactive overlays, scrollspy updates aria-current.

Focus styles use :focus-visible with strong outlines and .fc-focus-ring for components.

ARIA usage applied on menus, modals, toasts, and carousel slides.

Reduced motion support via @media (prefers-reduced-motion: reduce).

Color contrast targets WCAG AA between text and surface tokens.
